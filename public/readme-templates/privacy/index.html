Privacy Policy

README Templates · Last updated November 3, 2026

  • README Templates has no server and no user accounts of its own. We don't receive your data.
  • Your details and GitHub key stay on your device. The key is encrypted; your other details are not.
  • The app talks to GitHub using the key you provide, and only when you connect an account.
  • There are no analytics, ads or tracking.

What this covers

This policy covers the README Templates desktop app for Windows and Linux, including the Microsoft Store version, and the web version you can run yourself from the source code. The app helps you design a GitHub profile README and publish it to your own GitHub account.

What is stored on your device

All of this stays in the app's local storage on your device. None of it is sent to us.

DataDetailsProtection
GitHub access key Saved only if you choose to keep it on this device. Otherwise it's kept for the current session, or in memory only if encrypted storage isn't available. Encrypted with AES-256-GCM, using a key held on your device that the app's code can use but can't read.
Saved account details Your GitHub username, display name and avatar address, for the account menu. Not encrypted.
Data presets Details you save as a preset, such as your name, headline, location, website, email, social and support links, and template options. Not encrypted.
App preferences Your chosen template and form, the sidebar state and the last active account. Not encrypted.

Your GitHub profile data, sponsor data and unsaved edits are kept in memory while the app runs and are not saved to disk.

Encryption protects your key if the app's files are copied. It can't protect against malicious software already running on your device.

What is sent to GitHub

Without a connected account, the app makes no requests to GitHub for your profile and shows made-up sample data instead. When you connect an account, the app contacts api.github.com directly from your device, sending your key only to that address, in order to:

  • Read your profile, public repositories, contribution calendar, listed social accounts and, if you have a GitHub Sponsors profile, your public sponsors and goal. Private sponsors are not requested. Income figures are not requested.
  • Check your profile repository before publishing.
  • Write to your <username>/<username> repository, but only when you select Publish or Upload artwork. It can also create that repository, as public, if it doesn't exist.

What you publish becomes public on GitHub, including any email address or links you entered. GitHub handles this data under the GitHub Privacy Statement.

Other connections

  • Updates: versions downloaded from GitHub check github.com for new releases at launch and when you select Check for updates. The Microsoft Store version doesn't do this, because the Store handles its updates.
  • Images: the preview loads your avatar and your sponsors' avatars from GitHub, plus any image addresses you put in your own text. The site hosting an image can see your IP address, as with any web image.
  • Links: links you select open in your default browser, under that site's own privacy policy.
  • Microsoft: on Windows, the app runs on Microsoft's WebView2 runtime, and the Store version is delivered by the Microsoft Store. Both are covered by the Microsoft Privacy Statement.

What we don't collect

The app contains no analytics, advertising, tracking or crash-reporting tools. It has no server of ours to send anything to, so we have no copy of your data and can't see, sell or share it.

How to delete your data

  • One account: open the account menu and select the bin icon beside the account.
  • All saved keys: in the account menu, select Clear all saved keys. This also erases the device encryption key.
  • A preset: select it in the Data preset list, then select the bin icon.
  • Everything on this device: uninstall the app, then delete its data folder if it's still there, because uninstalling may not remove it:
    • Windows: %LOCALAPPDATA%\com.readmetemplates.studio
    • Windows, Microsoft Store version, if present: %LOCALAPPDATA%\Packages\DrAtomic.READMETemplates_cqr4nsexcrjqp
    • Linux: ~/.local/share/com.readmetemplates.studio
  • Your GitHub key: deleting it from the app doesn't cancel it. Revoke it in your GitHub token settings.
  • What you published: edit or delete the files in your profile repository on GitHub. Earlier versions stay in the repository's history until you remove them.

Children

The app isn't directed at children. Using its GitHub features requires a GitHub account, which is subject to GitHub's own age requirements.

Changes to this policy

If this policy changes, the new version will be posted on this page with a new date.
